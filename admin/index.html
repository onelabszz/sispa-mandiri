Cara Kerja Klaim Pengawas

Pengawas klaim sekolah via aplikasi PS → status Pending
Kepala Sekolah buka aplikasi KS → klik "Cek Pengawas" → konfirmasi/tolak
Jika diterima → status berubah menjadi Terkonfirmasi
Jika ada konflik/masalah → Admin bisa override via Edit Sekolah atau Assign Pengawas manual
Gunakan tombol Reset Klaim jika klaim deadlock atau salah
