Cara Kerja Klaim Pengawas

  1. Pengawas klaim sekolah via aplikasi PS → status otomatis Pending
  2. Kepala Sekolah buka aplikasi KS → klik "Cek Pengawas" → konfirmasi/tolak
  3. Jika diterima → status Terkonfirmasi
  4. Jika ada konflik/masalah → Admin bisa override via Edit Sekolah
  5. Gunakan tombol Reset Klaim jika klaim deadlock / salah
