Panduan Admin Dinas

Panduan untuk Admin Dinas Pendidikan — kelola akun sekolah & pengawas, monitor status klaim, assign pengawas manual, dan reset klaim saat ada konflik.

1. Pengenalan

Panel Admin adalah aplikasi web untuk Dinas Pendidikan mengelola akun yang bisa login di aplikasi KS & PS. Admin dapat:

  • Tambah/edit/hapus akun sekolah & pengawas
  • Monitor status klaim (sekolah mana yang sudah punya pengawas)
  • Assign pengawas manual (bypass konfirmasi KS)
  • Reset klaim saat ada konflik
  • Suspend akun yang bermasalah
ℹ️
URL AksesPanel Admin: https://onelabszz.github.io/sispa-mandiri/admin/. URL tidak dipublikasi ke KS/PS — hanya Dinas yang tahu.

2. Login

1
Buka URL Admin
Buka https://onelabszz.github.io/sispa-mandiri/admin/
2
Masukkan Kunci Admin
Ketik kunci admin (default: admin123). Tekan Enter atau klik "Masuk ke Panel".
⚠️
GANTI KUNCI!Kunci default admin123 WAJIB diganti sebelum distribusi. Edit file admin/index.html, cari baris const ADMIN_KEY = 'admin123';, ganti dengan kunci rahasia Anda.

3. Dashboard

Setelah login, Dashboard menampilkan 5 stat cards:

CardArti
Total SekolahSemua akun sekolah terdaftar
Total PengawasSemua akun pengawas aktif
TerkonfirmasiSekolah dengan pengawas yang sudah dikonfirmasi KS
Pending KlaimSekolah di-klaim PS tapi belum dikonfirmasi KS
Belum Ada PSSekolah tanpa pengawas pembina (perlu assign)

Warning Interaktif

Di bawah stat cards muncul warning jika ada masalah:

  • "X sekolah belum punya pengawas" → klik "Lihat →" untuk filter sekolah tanpa PS
  • "X klaim menunggu konfirmasi" → klik "Lihat →" untuk lihat pending
  • "X pengawas belum punya binaan" → klik "Lihat →" untuk lihat pengawas kosong

4. Data Sekolah

Menu Data Sekolah menampilkan tabel semua akun sekolah.

Kolom Tabel

  • NPSN
  • Nama Sekolah
  • Pengawas Pembina — nama + wilayah (jika sudah ada)
  • Klaim — status (✓ Terkonfirmasi / ⏳ Pending / ✕ Ditolak / —)
  • Status — Aktif / Suspend
  • Aksi — Edit, Toggle Aktif

Filter & Pencarian

  • Cari — NPSN/nama sekolah/pengawas
  • Klaim — Semua/Terkonfirmasi/Pending/Belum Ada
  • Pengawas — filter per pengawas
  • Pagination — 50 sekolah per halaman

Tambah Sekolah

1
Klik + Tambah Sekolah
Isi NPSN (8 digit), Nama Sekolah, dan opsional Assign Pengawas.
2
Pilih Pengawas (Opsional)
Kalau dipilih, langsung assign + konfirmasi (bypass KS). Kalau kosong, PS akan klaim nanti.
3
Klik Simpan
Sekolah ditambahkan ke sistem. KS bisa langsung login dengan NPSN tersebut.

Edit Sekolah

Klik tombol Edit di baris sekolah → modal muncul:

  • NPSN (readonly)
  • Nama Sekolah
  • Status (Aktif/Suspend)
  • Pengawas Pembina — dropdown pilih pengawas
  • Tombol Reset Klaim (jika sudah ada pengawas)

5. Assign Pengawas Manual

Gunakan ini jika:

  • KS tidak kunjung konfirmasi klaim PS
  • PS klaim sekolah yang salah (bukan wilayahnya)
  • Dinas mau override pilihan pengawas
1
Klik Edit di sekolah
Modal edit terbuka.
2
Pilih Pengawas Baru
Di dropdown "Assign / Ganti Pengawas", pilih pengawas yang dituju.
3
Klik Simpan
Modal konfirmasi muncul "Ganti Pengawas?" → klik "Ya, Ganti Pengawas".
4
Status Otomatis Confirmed
Pengawas baru langsung dapat akses. Status = Terkonfirmasi (bypass KS).
ℹ️
PS Lama Otomatis DilepasSaat admin override, pengawas lama kehilangan akses (di sistem, data lokal PS lama tetap aman). PS baru dapat notifikasi di "Refresh Status".

6. Reset Klaim

Gunakan ini jika:

  • KS menolak klaim PS terus-menerus
  • Klaim deadlock (tidak ada yang konfirmasi)
  • Perlu reset status agar PS lain bisa klaim
1
Klik Edit di sekolah yang ada pengawasnya
Tombol "Reset Klaim Pengawas" muncul di bagian bawah.
2
Klik Reset Klaim
Modal konfirmasi muncul dengan warning merah.
3
Ketik "RESET"
Di input field, ketik RESET (kapital) untuk mengaktifkan tombol.
4
Klik "Reset Klaim"
Klaim terhapus dari database. Sekolah kembali "belum ada pengawas". PS lain bisa klaim.
⚠️
Data Lokal PS Tidak TerpengaruhReset ini hanya menghapus klaim di database. Data lokal PS lama (IndexedDB) tetap ada di laptop PS tersebut. Tapi PS tidak bisa lagi kirim/validasi JSON untuk sekolah ini.

7. Data Pengawas

Menu Data Pengawas untuk mengelola akun pengawas.

Kolom Tabel

  • NIP
  • Nama Pengawas
  • Wilayah
  • Binaan — jumlah sekolah yang di-klaim
  • Status — Aktif / Suspend

Filter & Sort

  • Sort — Nama A-Z / Binaan Terbanyak / Binaan Sedikit
  • Checkbox "Hanya Belum Punya Binaan" — untuk lihat pengawas yang butuh tugas
  • Cari — NIP/nama/wilayah

Tambah Pengawas

Klik + Tambah Pengawas → isi NIP (wajib), Nama (wajib), Wilayah. Setelah simpan, pengawas bisa login di aplikasi PS.

Suspend Pengawas

Klik tombol Power di baris pengawas → konfirmasi. Pengawas yang di-suspend tidak bisa login.

9. Alur Klaim Pengawas

Pemahaman lengkap alur klaim antara PS & KS:

StepAktorAksiStatus
1AdminInput sekolah & pengawas ke sistem—
2PSLogin → Pilih DB → Klaim sekolahPending
3KSLogin → Cek Pengawas → KonfirmasiTerkonfirmasi
4PSRefresh Status → lihat badge ✓Terkonfirmasi

Jika Ada Konflik

  • KS menolak klaim → status kembali null, PS lain bisa klaim
  • PS keliru klaim → Admin Reset Klaim → PS lain klaim
  • PS di-suspend → klaim otomatis hangus, KS dapat notifikasi
  • Dinas mau ganti PS → Admin Assign Pengawas → otomatis confirmed

10. FAQ

Bagaimana kalau ada sekolah yang NPSN-nya salah input?
Hapus sekolah lama (klik Edit → tidak ada tombol hapus di modal. Untuk hapus, buka menu Data Sekolah → kalau ada tombol hapus). Atau edit nama sekolah, NPSN tidak bisa diedit. Kalau NPSN salah, hapus & input ulang.
Kalau ada PS baru masuk, apakah klaim sekolah sebelumnya hilang?
Tidak. Klaim sekolah yang sudah confirmed oleh PS lama tetap. PS baru harus klaim sekolah sendiri atau admin assign manual.
Bisa 1 sekolah dipegang 2 pengawas?
Tidak. 1 sekolah = 1 pengawas. Kalau perlu backup, assign manual ke pengawas lain akan menggantikan pengawas lama.
Kenapa PS tidak bisa login?
Cek: (1) NIP sudah terdaftar, (2) Status aktif (bukan suspend), (3) Koneksi internet PS stabil, (4) URL Supabase di config.js benar.
Bagaimana kalau saya lupa kunci admin?
Lupa kunci admin = tidak bisa akses panel. Solusi: buka file admin/index.html, cari const ADMIN_KEY = '...'; dan baca kuncinya. Kalau tidak bisa buka file, minta developer reset.
Apakah admin bisa lihat data supervisi KS?
Tidak. Admin hanya kelola akun (NPSN, pengawas). Data supervisi tetap di laptop KS masing-masing — tidak sampai ke server.
Bagaimana cara backup data admin?
Panel admin tidak punya fitur backup (data di Supabase, sudah di-backup otomatis oleh Supabase). Untuk ekspor manual, buka Supabase Dashboard → Table Editor → Export CSV.
Bagaimana kalau Supabase ter-pause?
GitHub Actions sudah otomatis ping setiap 3 hari. Kalau tetap paused, buka Supabase Dashboard → klik "Restore Project" → tunggu 2 menit.
