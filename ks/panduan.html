Panduan Kepala Sekolah

Panduan lengkap penggunaan aplikasi SISPA Mandiri untuk Kepala Sekolah — dari instalasi awal, setup identitas, alur supervisi akademik, hingga backup data.

1. Pengenalan

SISPA Mandiri adalah aplikasi semi-online untuk Kepala Sekolah dalam melakukan supervisi akademik secara mandiri. Aplikasi ini berbasis Modul 5 (Supervisi Akademik pada Pembelajaran Mendalam termasuk Koding & Kecerdasan Artifisial).

ℹ️
Tanpa ServerSetelah install sekali, aplikasi bisa dipakai sepenuhnya offline. Data tersimpan di browser laptop Anda.

2. Pasang Aplikasi (PWA)

Aplikasi berbentuk web app yang bisa dipasang seperti aplikasi desktop/HP. Setelah dipasang, bisa dipakai tanpa internet.

Di Laptop (Chrome/Edge)

1
Buka URL aplikasi
Kunjungi https://onelabszz.github.io/sispa-mandiri/ks/
2
Klik ikon Install di address bar
Ikon kecil (kotak dengan panah) muncul di sebelah kanan URL bar.
3
Klik "Install"
Aplikasi ditambahkan ke desktop dan Start Menu.

Di HP Android

Buka URL di Chrome → ketuk menu ⋮ (titik tiga) → pilih "Install app".

Di iPhone/iPad (Safari)

Buka URL di Safari → ketuk ikon Share → pilih "Add to Home Screen".

💡
Gunakan Chrome/EdgeAplikasi optimal di Chrome atau Edge versi terbaru. Hindari mode Incognito (data akan hilang saat tab ditutup).

3. Login & Setup Profil

Saat pertama membuka aplikasi, Anda akan diminta memasukkan NPSN sekolah. Data akun dikelola oleh Dinas Pendidikan.

1
Masukkan NPSN
8 digit NPSN sekolah Anda. Contoh: 20311457. Sistem akan memverifikasi ke database Dinas.
2
Lengkapi Profil
Setelah NPSN terverifikasi, isi Nama Lengkap & Gelar (wajib) dan NIP (opsional). Data ini dipakai untuk tanda tangan laporan.
3
Masuk Dashboard
Anda akan diarahkan ke Dashboard. Klik "Simpan & Masuk".
⚠️
Perangkat Dipakai KS Lain?Jika laptop Anda pernah dipakai KS lain, akan muncul peringatan "Perangkat Sudah Punya Data". Pilih Ekspor Dulu untuk backup data lama, atau Batal untuk login dengan NPSN yang benar.

4. Dashboard

Halaman utama setelah login. Berisi:

  • Kartu Profil KS — nama, NPSN, NIP (klik "Edit Profil" untuk ubah)
  • Widget Pengawas Pembina — status pengawas Anda, tombol "Cek Pengawas"
  • Stat Cards — Total Guru, Total Supervisi, Sudah Dinilai
  • Papan Supervisi — progress bar 3T, Akademik, Coaching + warning guru belum disupervisi
  • Perlu Perhatian — warning interaktif (klik untuk navigasi)
  • Distribusi Tipe Guru — kuadran Glickman
  • Aktivitas Terakhir — 5 sesi terbaru
ℹ️
Backup ReminderJika belum backup >7 hari, akan muncul banner kuning "Waktunya Backup" di atas Dashboard. Klik "Ekspor Sekarang" untuk backup.

5. Data Guru

Menu Data Guru untuk mengelola daftar guru di sekolah Anda.

Tambah Manual

Klik + Tambah Guru → isi Nama (wajib), NIP, Mapel, Kelas, Status Kepegawaian (PNS/PPPK/Non ASN).

Import CSV (Bulk)

1
Klik 📥 Impor CSV
Muncul modal dengan 2 tab: Upload File dan Paste CSV.
2
Pilih Metode
Upload File: Download template → isi di Excel → Save As CSV UTF-8 → upload.
Paste CSV: Copy dari Excel → paste ke textarea → klik Lanjut Preview.
3
Review Preview
Sistem menampilkan preview per baris (✓ valid, ⚠ duplikat, ✗ error). Klik "Impor" untuk konfirmasi.
ℹ️
Format Kolomnama ; nip ; mapel ; kelas ; peg. Separator titik-koma. Duplikat (nama + NIP sama) otomatis dilewati.

8. Supervisi 3 Tahap

Menu Supervisi 3 Tahap — fitur utama SISPA. Wizard 3 tahap dengan panduan Modul 5.

Mulai Supervisi

Klik + Mulai Supervisi → pilih guru → isi tanggal → mulai wizard.

Tahap 1 — Pra-Observasi

Panduan Modul 5:

  • Tanyakan: "Apa tujuan pembelajaran yang ingin dicapai hari ini?"
  • Tanyakan: "Bagaimana Anda menerapkan Prinsip Pembelajaran Mendalam?"
  • Tanyakan: "Apa aspek fokus yang ingin kita amati bersama?"
  • Sepakati bersama 1 aspek fokus

Isi: Tujuan, Strategi, Asesmen, Prinsip PM, Pengalaman Belajar, 8 DPL, Aspek Fokus, Kesiapan Guru, Link Dokumen.

Jika guru sudah dinilai tipe, muncul kartu Panduan Pendekatan sesuai tipe (Directive untuk Dropout, Non-Directive untuk Professional).

Tahap 2 — Observasi

Panduan Modul 5:

  • Catat FAKTA (apa dilihat & didengar), bukan opini
  • Contoh fakta: "Guru memberi waktu tunggu 5 detik sebelum murid menjawab"
  • Bukan fakta: "Guru kurang memberi waktu berpikir"

Isi: Aktivitas Guru, Aktivitas Murid, Momen PM, Integrasi KKA, Durasi, Link Video/Foto.

Tahap 3 — Pasca-Observasi

Panduan Modul 5:

  • Ajukan 7 pertanyaan refleksi secara berurutan
  • Jangan interupsi saat guru berbicara
  • Respons "Menanyakan" jika guru belum menyadari
  • Respons "Memberitahu" jika guru buntu

Isi: 7 pertanyaan refleksi + respons + RTL (Aksi, Waktu, Dukungan, Indikator).

✅
Bisa Simpan DraftKlik "Simpan Draft" di step mana pun. Kembali kapan saja via menu Supervisi → tombol "Lanjut".

9. Obs. Akademik

Menu Obs. Akademik — 19 indikator pembelajaran digital dengan skor 1-4.

Alur

  1. Klik + Mulai Akademik Baru
  2. Isi identitas: Guru, Tanggal, Mapel, Materi, Durasi
  3. Beri skor per indikator (1-4): 1=Belum, 2=Mulai, 3=Berkembang, 4=Mahir
  4. Isi catatan per indikator + catatan tambahan + kekuatan + area pengembangan + RTL
  5. Pilih: Simpan Draft (bisa lanjut nanti) atau Selesaikan (final, readonly)

List & Status

StatusAksi
⏳ DraftKlik "Lanjut" untuk edit, "Hapus" untuk hapus
✓ SelesaiKlik "Lihat" (readonly), "Cetak" (PDF), "Hapus"

Klik 🖨 Cetak Rekap di kanan atas untuk cetak semua sesi dalam 1 halaman.

10. Obs. Coaching

Menu Obs. Coaching — 8 indikator STAR-GROW untuk percakapan coaching pasca-observasi.

Indikator

  • S — Situation (gali konteks)
  • T — Target (gali tujuan)
  • A — Action (gali langkah)
  • R — Result (gali dampak)
  • G — Goal (rumuskan tujuan pengembangan)
  • R — Reality (identifikasi kondisi nyata)
  • O — Options (dorong alternatif)
  • W — Will (komitmen tindak lanjut)

Alur sama seperti Akademik: draft/selesai, RTL multi-baris (klik + Tambah Baris RTL), cetak, hapus.

Filter

  • Cari nama guru
  • Jenis: 3 Tahap / Akademik / Coaching
  • Status: Selesai / Draft
  • Bulan tertentu

Cetak Rekap Semester

Edit nama sekolah, NPSN, nama KS, NIP, PIN. Klik Simpan Pengaturan.

Pengawas Pembina Saya

1
Klik 🔄 Cek Pengawas Dabin
Sistem cek ke database apakah pengawas sudah klaim sekolah Anda.
2
Konfirmasi Pengawas
Jika ada pengawas klaim, muncul modal konfirmasi. Klik "Konfirmasi" jika benar, "Tolak" jika salah.

⚠️
WAJIB: Backup MingguanData disimpan di browser laptop. Jika clear browsing data, uninstall Chrome, atau laptop rusak, data bisa hilang. Backup JSON mingguan adalah satu-satunya cara aman.

14. FAQ

Data saya hilang setelah clear browsing data, bagaimana?
Data tidak bisa dipulihkan kecuali ada backup JSON. Ini alasan mengapa backup mingguan sangat penting. Ke depannya: backup rutin ke Google Drive, dan jangan pernah clear browsing data tanpa backup dulu.
Bisa dipakai di HP dan laptop bersamaan?
Bisa, tapi data tidak tersinkron otomatis. Setiap device punya data sendiri. Untuk memindah: ekspor JSON di device lama → impor di device baru.
Bagaimana cara kirim data ke Pengawas?
Pengaturan → Ekspor JSON → file terunduh → kirim ke Pengawas via WhatsApp atau Email. Pengawas akan impor file tersebut di aplikasi PS.
Lupa PIN?
Tidak ada recovery otomatis. Jika lupa, Anda harus reset aplikasi (data hilang) lalu impor backup JSON. Catat PIN di tempat aman.
Laptop dipinjam KS lain, muncul warning?
Iya, sistem akan memperingatkan "Perangkat Sudah Punya Data". Pilih "Ekspor Dulu" untuk backup data lama, atau "Batal" untuk login NPSN yang benar.
Aplikasi lemot, kenapa?
Tutup tab lain, restart browser, cek penyimpanan laptop (minimal 100 MB free), pastikan Chrome versi terbaru. Jika masih lemot, kemungkinan sudah terlalu banyak data (>1000 sesi).
Bisa edit sesi yang sudah "Selesai"?
Tidak bisa. Setelah finalisasi, data readonly. Jika perlu revisi, hubungi Pengawas atau hapus & buat sesi baru.
Apakah aplikasi ini gratis?
Ya, 100% gratis. Tidak ada biaya bulanan, tidak ada iklan, tidak ada data yang dikirim ke server manapun.

15. Tips Profesional

💾
Backup MingguanSetiap Jumat atau Senin, ekspor JSON dan simpan ke Google Drive. Beri nama dengan tanggal (misal SISPA_Backup_2025-10-20.json) agar mudah dicari.
📝
Catat Fakta, Bukan OpiniSaat observasi, tulis apa yang dilihat dan didengar (misal "guru bertanya kepada 5 murid berbeda"), bukan interpretasi ("guru kurang memeratakan perhatian").
🎯
Supervisi = Membantu, Bukan MenilaiFokus pada pertumbuhan guru. Refleksi dengan pertanyaan terbuka ("Bagaimana perasaan Anda setelah mengajar?"), bukan penilaian ("Anda kurang baik dalam X").
📅
Jadwalkan Supervisi TeraturIdealnya setiap guru disupervisi minimal 1x per semester. Buat program di awal semester dan konsisten menjalankannya.
📤
Kirim ke Pengawas RutinJangan tunggu akhir semester. Kirim JSON ke Pengawas setiap bulan atau 2 minggu agar Pengawas bisa beri feedback cepat.
