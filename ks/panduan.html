Panduan Kepala Sekolah

Panduan lengkap penggunaan aplikasi SISPA Mandiri untuk Kepala Sekolah — dari instalasi awal, setup identitas sekolah, alur supervisi akademik, hingga backup data.

Pengenalan

SISPA Mandiri adalah aplikasi semi-online untuk Kepala Sekolah dalam melakukan supervisi akademik secara mandiri. Aplikasi ini 100% gratis dan bekerja tanpa server cloud — semua data tersimpan di laptop atau HP Anda.

Tanpa Internet, Tanpa Server Setelah install sekali, aplikasi bisa dipakai sepenuhnya offline. Data disimpan di browser laptop Anda (localStorage). Anda hanya butuh internet saat pertama kali buka dan saat kirim file ke Pengawas.

Yang Bisa Anda Lakukan

Dashboard
Ringkasan guru, supervisi, dan peringatan.
Data Guru

Pasang & Akses Aplikasi

Aplikasi ini berbentuk web app (PWA) yang bisa dipasang seperti aplikasi desktop atau HP. Setelah dipasang, aplikasi jalan penuh tanpa internet.

Gunakan Chrome atau Edge Aplikasi optimal di Chrome atau Edge versi terbaru. Firefox dan Safari bisa dipakai tapi fitur install mungkin berbeda. Hindari mode Incognito (data akan hilang saat tab ditutup).

Cara Memasang di Laptop (Chrome/Edge)

1
Buka URL aplikasi
Kunjungi link yang diberikan Dinas atau Pengawas. Contoh: https://username.github.io/sispa-mandiri/ks/
2
Klik ikon Install di address bar
Muncul ikon kecil (kotak dengan panah atau tulisan "Install") di sebelah kanan address bar. Klik ikon tersebut.
3
Klik "Install"
Dialog konfirmasi muncul. Klik Install. Aplikasi akan ditambahkan ke desktop dan Start Menu.
4
Buka dari desktop
Ikon SISPA muncul di desktop. Klik untuk membuka. Aplikasi akan tampil fullscreen tanpa address bar browser.

Cara Memasang di HP Android

1
Buka URL di Chrome HP
Sama seperti di laptop. Ketik atau tempel URL di Chrome.
2
Ketuk menu ⋮ (titik tiga)
Di pojok kanan atas Chrome.
3
Pilih "Install app" atau "Tambahkan ke Home Screen"
Aplikasi akan muncul sebagai ikon di home screen.

Untuk iPhone/iPad (Safari)

1
Buka URL di Safari
Wajib pakai Safari, bukan Chrome iOS.
2
Ketuk tombol Share
Ikon kotak dengan panah ke atas di bagian bawah browser.
3
Pilih "Add to Home Screen"
Ikon SISPA akan muncul di home screen iPhone.

Setup Awal

Saat pertama kali membuka aplikasi, Anda akan diminta mengisi identitas sekolah. Ini hanya perlu dilakukan sekali.

1
Isi Nama Sekolah
Nama lengkap sekolah Anda. Contoh: SDN 1 Sukamaju. Wajib diisi.
2
Isi NPSN
8 digit NPSN sekolah Anda. Bisa dilihat di profil sekolah atau tanyakan operator. Wajib diisi — dipakai Pengawas untuk mengelompokkan data.
3
Isi Nama Kepala Sekolah dan NIP
Nama lengkap dengan gelar. Contoh: Dra. Siti Aminah, M.Pd. NIP wajib diisi untuk tanda tangan laporan.
4
Klik "Simpan & Mulai"
Anda akan diarahkan ke Dashboard.
Aktifkan PIN setelah setup Setelah masuk Dashboard, buka Pengaturan → set PIN 4 digit. PIN melindungi data jika laptop Anda dipinjam orang lain.

Alur Supervisi Lengkap

Alur kerja yang direkomendasikan dari awal hingga akhir semester. Ikuti urutan ini untuk hasil terbaik.

1. Input Data Guru — Masukkan semua guru di sekolah Anda. Bisa manual atau impor CSV.
2. Nilai Profil Tipe Guru — Tentukan tipe Glickman (Dropout/Unfocused/Analytical/Professional).
3. Susun Program — Rencanakan jadwal supervisi per periode.
4. Lakukan Supervisi 3 Tahap — Pra-observasi, observasi, pasca-observasi.
5. Observasi (opsional) — Akademik atau Coaching untuk guru tertentu.
6. Analisis Data — Lihat grafik PM, pengalaman belajar, DPL, KKA.
7. Cetak Laporan — Print PDF untuk arsip dan laporan ke Dinas.
8. Backup & Kirim ke Pengawas — Ekspor JSON, kirim via WhatsApp.

1. Input Data Guru

Menu Data Guru di sidebar kiri. Anda bisa menambah guru satu per satu atau mengimpor dari file CSV untuk efisiensi.

Tambah Manual

1
Klik "+ Tambah Guru"
Tombol biru di kanan atas.
2
Isi form
Nama lengkap (wajib), NIP, mata pelajaran, kelas, dan status kepegawaian (PNS/PPPK/Non ASN).
3
Klik Simpan
Guru muncul di tabel. Ulangi untuk guru lain.

Impor dari CSV (Banyak Guru Sekaligus)

1
Klik "Impor CSV"
Tombol abu-abu di kanan atas.
2
Download template
Klik "Download Template CSV". File template_guru_sispa.csv akan terunduh.
3
Buka di Excel dan isi data
Format kolom: nama; nip; mapel; kelas; peg. Hapus baris contoh, isi dengan data guru Anda.
4
Save As → CSV UTF-8
Penting: pilih CSV UTF-8 saat save agar karakter khusus tetap terbaca.
5
Upload file
Klik "Pilih File", pilih CSV yang sudah diisi. Sistem akan menampilkan preview per baris — valid, duplikat, atau error.
6
Klik "Impor"
Semua guru valid langsung masuk. Duplikat (nama + NIP sama) otomatis dilewati.

2. Nilai Profil Tipe Guru

Menu Profil Tipe Guru. Anda menentukan level abstraksi (kemampuan analisis) dan komitmen (kesediaan waktu) setiap guru. Sistem akan otomatis mengklasifikasikan tipe Glickman dan merekomendasikan pendekatan supervisi.

Abstraksi Komitmen Tipe Pendekatan
Rendah Rendah Dropout Directive-Control (Mentoring)
Rendah Tinggi Unfocused Directive-Informational (Mentoring)
Tinggi Rendah Analytical Collaborative (Coaching)
Tinggi Tinggi Professional Non-Directive (Coaching)
Bagaimana menilai abstraksi & komitmen? Abstraksi rendah: guru cenderung bingung saat ada masalah pembelajaran, tidak tahu harus mulai dari mana. Abstraksi tinggi: guru mampu menganalisis masalah sendiri dan mencari solusi. Komitmen rendah: guru enggan meluangkan waktu untuk perubahan. Komitmen tinggi: guru bersedia berkorban waktu untuk perbaikan.

3. Susun Program Supervisi

Menu Program Supervisi. Rencanakan jadwal supervisi per periode (misal semester ganjil 2025/2026). Ini adalah rencana, bukan jadwal wajib.

1
Klik "+ Tambah Program"
Isi form: pilih guru, periode (default 2025/2026-Ganjil), tanggal rencana.
2
Ulangi untuk setiap guru
Idealnya setiap guru punya minimal 1 program supervisi per semester.

4. Lakukan Supervisi 3 Tahap

Menu Supervisi 3 Tahap. Ini adalah fitur utama SISPA. Anda memandu guru melalui tiga tahap pembelajaran bermakna.

Tahap 1 — Pra-Observasi

Percakapan sebelum observasi kelas. Fokus pada perencanaan pembelajaran.

  • Tujuan pembelajaran — apa yang ingin dicapai guru?
  • Strategi pedagogis — bagaimana cara mencapainya?
  • Rencana asesmen — bagaimana mengukur ketercapaian?
  • Prinsip PM — centang yang sesuai: Berkesadaran, Bermakna, Menggembirakan
  • Pengalaman belajar — Memahami, Mengaplikasi, Merefleksi
  • 8 Dimensi Profil Lulusan — centang yang akan dikembangkan
  • Aspek fokus observasi — pilih satu fokus utama (misal: teknik bertanya)
  • Kesiapan guru — siap, ragu, atau belum siap?

Tahap 2 — Observasi Kelas

Anda masuk kelas, mengamati pembelajaran, dan mencatat fakta.

  • Aktivitas guru — apa yang dilakukan guru? (fakta, bukan opini)
  • Aktivitas murid — bagaimana respons murid?
  • Momen Pembelajaran Mendalam — centang momen yang terjadi
  • Integrasi Koding/AI (KKA) — apakah guru menggunakan?
  • Durasi observasi — berapa menit?

Tahap 3 — Pasca-Observasi

Percakapan refleksi setelah observasi. Guru merefleksi, Anda memandu.

  • 7 pertanyaan refleksi — guru menjawab, Anda menandai respons (menanyakan/memberitahu)
  • RTL (Rencana Tindak Lanjut) — aksi konkret, waktu, dukungan, indikator keberhasilan
Bisa disimpan sebagai draft Anda tidak perlu menyelesaikan ketiga tahap sekaligus. Klik Simpan Draft di step mana pun. Kembali kapan saja melalui menu Supervisi.
Warning guru sudah disupervisi Jika guru sudah pernah disupervisi di periode yang sama, akan muncul tanda peringatan kuning. Ini bukan larangan — Anda tetap bisa supervisi ulang untuk pembinaan intensif.

5. Observasi Akademik / Coaching

Dua fitur tambahan untuk melengkapi supervisi 3 tahap. Bersifat opsional, gunakan sesuai kebutuhan.

Observasi Akademik (19 Indikator)

Fokus pada pembelajaran berbasis digital. Setiap indikator diberi skor 1-4:

  • 1 = Belum terlihat
  • 2 = Mulai terlihat
  • 3 = Berkembang
  • 4 = Mahir

Indikator dibagi 6 kategori: Perencanaan, Pemanfaatan Media, Interaksi Murid, Literasi & Etika, Asesmen Digital, Pengelolaan Kelas. Setiap indikator bisa diberi catatan bukti.

Observasi Coaching (8 Indikator STAR-GROW)

Fokus pada percakapan coaching pasca-observasi. Mengukur kualitas pertanyaan supervisor:

  • S — Situation: menggali konteks
  • T — Target: menggali tujuan
  • A — Action: menggali langkah konkret
  • R — Result: menggali dampak
  • G — Goal: membantu merumuskan tujuan pengembangan
  • R — Reality: identifikasi kondisi nyata
  • O — Options: dorong alternatif solusi
  • W — Will: komitmen tindak lanjut

6. Analisis Data

Menu Analisis PM & KKA. Setelah beberapa supervisi, Anda bisa melihat pola:

  • Grafik prinsip pembelajaran mendalam (berkesadaran, bermakna, menggembirakan)
  • Grafik pengalaman belajar (memahami, mengaplikasi, merefleksi)
  • Bar chart 8 Dimensi Profil Lulusan
  • Persentase integrasi Koding/AI (KKA)

Data ini membantu Anda melihat kecenderungan sekolah dan menentukan fokus pembinaan guru.

7. Cetak Laporan

Menu Laporan & Riwayat. Semua sesi terkumpul di sini. Setiap sesi bisa dicetak sebagai PDF profesional dengan tanda tangan ganda (KS dan Guru).

Klik Cetak → dialog print browser terbuka → pilih "Save as PDF" → simpan. Template sudah dioptimalkan untuk kertas A4.

Detail Fitur

Dashboard

Ringkasan cepat: total guru, total sesi, distribusi tipe guru, peringatan guru belum dinilai, dan 5 aktivitas terakhir. Buka setiap hari untuk memantau progres.

Pengaturan

Ubah identitas sekolah & KS, ganti PIN, ekspor/impor backup, dan reset data. Semua di satu tempat.

Backup & Sinkronisasi

WAJIB: Backup mingguan Data disimpan di browser laptop Anda. Jika Anda clear browsing data, uninstall Chrome, atau laptop rusak, data bisa hilang. Backup JSON mingguan adalah satu-satunya cara aman.

Cara Backup

1
Buka Pengaturan
Menu sidebar → Pengaturan.
2
Klik "Ekspor JSON"
File SISPA_Backup_YYYY-MM-DD.json akan terunduh.
3
Simpan ke Google Drive atau flashdisk
Jangan hanya di folder Downloads — bisa hilang saat reinstall.

Cara Restore (Pindah Device)

1
Install aplikasi di device baru
Buka URL, install PWA seperti biasa.
2
Setup minimal
Isi identitas sekolah (bisa sementara, nanti akan ditimpa).
3
Impor JSON
Pengaturan → Impor JSON → pilih file backup → konfirmasi. Semua data kembali.

Kirim ke Pengawas

Secara berkala (mingguan atau akhir semester), kirim file JSON ke Pengawas via WhatsApp atau Email. Pengawas akan mengimpor data Anda untuk analisis.

Ekspor JSON dari Pengaturan
Kirim file ke Pengawas via WhatsApp atau Email
Pengawas impor → analisis → laporan ke Dinas

PIN & Keamanan

PIN adalah lapisan keamanan opsional. Sangat direkomendasikan jika laptop Anda kadang dipinjam orang lain.

Set PIN

1
Buka Pengaturan
Menu sidebar → Pengaturan.
2
Isi field PIN
4 digit angka. Contoh: 1234. Jangan gunakan PIN yang mudah ditebak.
3
Simpan
Setelah disimpan, buka aplikasi berikutnya akan diminta PIN.
Lupa PIN? Tidak ada recovery otomatis. Jika lupa, Anda harus reset aplikasi (data hilang) lalu impor backup JSON. Catat PIN di tempat aman atau gunakan PIN yang tidak akan lupa (tanggal lahir, nomor absen, dsb).

Kunci Manual

Klik avatar di kanan atas → Kunci Aplikasi. Layar PIN muncul. Siapa pun yang mencoba membuka harus tahu PIN. Berguna saat meninggalkan laptop di ruang guru.

FAQ & Troubleshooting

Data saya hilang setelah clear browsing data, bagaimana?
Sayangnya data tidak bisa dipulihkan jika tidak ada backup. Ini alasan mengapa backup JSON mingguan sangat penting. Ke depannya: backup rutin ke Google Drive, dan jangan pernah clear browsing data tanpa backup dulu.
Bisa dipakai di HP dan laptop bersamaan?
Bisa, tapi data tidak tersinkron otomatis. Setiap device punya data sendiri. Untuk memindah: ekspor JSON di device lama → impor di device baru. Atau pakai hanya satu device untuk menghindari kebingungan.
Aplikasi lemot, kenapa?
Coba: (1) tutup tab lain yang banyak, (2) restart browser, (3) cek penyimpanan laptop (minimal 100 MB free), (4) pastikan Chrome versi terbaru. Jika masih lemot, kemungkinan sudah terlalu banyak data (>1000 sesi) — hubungi Pengawas untuk panduan.
Bisa edit sesi supervisi yang sudah "Selesai"?
Ya. Buka menu Supervisi → klik Edit pada sesi. Anda bisa mengubah semua isian. Klik "Selesaikan" lagi untuk menyimpan perubahan.
Bagaimana cara hapus guru?
Data Guru → klik tombol Hapus di baris guru. Sistem akan memperingatkan jika guru punya riwayat supervisi. Jika tetap dihapus, riwayat tetap ada tapi nama tampil "?" di laporan. Lebih baik arsipkan (tidak perlu dihapus).
Format CSV impor gagal, kenapa?
Pastikan: (1) separator titik-koma ; bukan koma ,, (2) Save As pilih CSV UTF-8, (3) header kolom nama;nip;mapel;kelas;peg di baris pertama, (4) tidak ada baris kosong di tengah.
Apakah aplikasi ini benar-benar gratis?
Ya, 100% gratis dan open source. Tidak ada biaya bulanan, tidak ada iklan, tidak ada data yang dikirim ke server manapun. Anda hanya butuh laptop/HP dan koneksi internet sekali saat pertama install.
Bisa dipakai 2 KS di satu laptop?
Tidak direkomendasikan. Satu device = satu KS. Jika ada pergantian KS (rotasi jabatan), KS baru harus ekspor backup dari KS lama, hapus semua data, setup ulang dengan identitas baru, lalu impor kembali backup (data lama akan tercampur). Hubungi Pengawas untuk panduan rotasi.

Tips Profesional

Backup mingguan, wajib Setiap Jumat atau Senin, ekspor JSON dan simpan ke Google Drive. Beri nama file dengan tanggal (misal SISPA_Backup_2026-10-20.json) agar mudah dicari.
Catat fakta, bukan opini Saat observasi, tulis apa yang dilihat dan didengar (misal "guru bertanya kepada 5 murid berbeda"), bukan interpretasi ("guru kurang memeratakan perhatian").
Supervisi = membantu, bukan menilai Fokus pada pertumbuhan guru. Refleksi dengan pertanyaan terbuka ("Bagaimana perasaan Anda setelah mengajar?"), bukan penilaian ("Anda kurang baik dalam X").
Jadwalkan supervisi teratur Idealnya setiap guru disupervisi minimal 1x per semester. Buat program di awal semester dan konsisten menjalankannya.
Kirim ke Pengawas rutin Jangan tunggu akhir semester. Kirim JSON ke Pengawas setiap bulan atau setiap 2 minggu, agar Pengawas bisa memberikan feedback cepat.

Butuh bantuan lebih lanjut? Hubungi Pengawas Pembina atau admin Dinas Pendidikan setempat.
