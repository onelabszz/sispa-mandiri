Panduan Pengawas

Panduan lengkap untuk Pengawas — dari menerima data KS, analisis kinerja, evaluasi kepala sekolah, hingga cetak rekap ke Dinas Pendidikan.

1. Pengenalan

SISPA Pengawas adalah aplikasi untuk mengelola data supervisi dari banyak sekolah binaan. Anda menerima file JSON dari KS, impor, analisis, dan buat laporan.

ℹ️
Data Tersimpan LokalSemua data tersimpan di laptop Anda (IndexedDB). Cukup untuk 500+ sekolah.

Fitur Utama

📥
Import JSON
Merge otomatis, deteksi duplikat.
📊
Dashboard
Agregat multi-sekolah.
📈
Analisis
Coverage, benchmark, KKA.
🎯
Evaluasi KS
30 indikator manual.
📄
Laporan
Rekap PDF + CSV.
🔄
Klaim
Sinkron dengan KS.

4. Dashboard

  • 4 Stat Cards — Total Sekolah, Total Guru, Dinilai Tipe, Total Sesi
  • Widget Pending Klaim — sekolah yang sudah Anda klaim tapi belum dikonfirmasi KS
  • Peta Kuadran Glickman — distribusi tipe guru lintas sekolah

  • Aktivitas Terbaru — 6 sesi terakhir

5. Sekolah Binaan

Menu Sekolah Binaan untuk mengelola sekolah yang Anda awasi. Ada 3 cara menambah sekolah:

Cara 1 — Pilih dari Database (Direkomendasikan)

1
Klik 🔍 Pilih dari DB
Modal muncul dengan daftar semua sekolah dari database Dinas.
2
Cari & Centang Sekolah
Cari NPSN atau nama sekolah. Centang sekolah yang jadi binaan Anda.
3
Klik "Klaim & Tambahkan"
Sistem klaim ke database (status: pending). KS akan konfirmasi.

Cara 2 — Import CSV

Klik 📥 Import CSV di toolbar. Format: npsn ; nama_sekolah. Berguna untuk import banyak sekolah sekaligus.

Cara 3 — Import JSON dari KS

Ketika KS kirim file JSON via WhatsApp, klik 📁 Import JSON KS → upload file.

ℹ️
Validasi JSONSistem memvalidasi NPSN (harus binaan Anda) + field pengawas_nip di file (harus NIP Anda). File dari pengawas lain akan ditolak.

Klik 🔄 Refresh Status untuk cek ulang status klaim dari KS.

6. Detail Sekolah

Klik 👁 Detail di baris sekolah untuk masuk halaman detail dengan 4 tab:

  • Profil Guru — semua guru dengan abstraksi, komitmen, tipe Glickman
  • Program — rencana supervisi per periode
  • Supervisi — semua sesi (3T, Supervisi Digitalisasi, Coaching) di sekolah tersebut
  • Progress Matrix — grid 3 kolom ✓/✗ per guru × jenis supervisi

Tombol 📥 Export CSV di kanan atas untuk download rekap sekolah ini.

10. Evaluasi Kinerja KS

Menu Evaluasi Kinerja KS — penilaian manual 30 indikator terhadap kinerja pembelajaran Kepala Sekolah (bukan evaluasi otomatis).

Struktur Instrumen

Alur

1
Klik + Evaluasi Baru
Pilih sekolah → KS otomatis terisi, periode & tanggal default.
2
Isi 30 Indikator
Skor 0-3 per indikator (0=belum, 1=mulai, 2=berkembang, 3=mahir).
3
Isi Catatan & RTL
Catatan per komponen + RTL keseluruhan.
4
Simpan Draft atau Finalisasi
Draft = bisa diedit, Final = readonly + tombol Cetak PDF.

Kategori Predikat

  • ≥91% — Sangat Baik
  • 80-90% — Baik
  • 71-79% — Cukup
  • <71% — Kurang

13. FAQ

Berapa banyak sekolah yang bisa ditangani?
Secara teknis tidak ada batas keras — IndexedDB bisa menampung ratusan MB. Untuk 100-200 sekolah masih aman. Untuk >500 sekolah, backup bulanan rutin.
Import file yang sama berulang, aman?
Ya, aman di mode Merge. Sistem mendeteksi tidak ada yang baru, jadi tidak ada duplikasi. Cocok untuk sync rutin.
KS sudah hapus data, tapi file JSON lama masih ada?
Import ulang file dengan mode Replace. Data lama di aplikasi akan diganti total dengan data dari file. Efeknya = "mengembalikan" state ke waktu file dibuat.
Apa beda Merge vs Replace?
Merge (default) — data lama dipertahankan, hanya item baru/diubah yang di-update. Cocok untuk sync rutin.
Replace — data lama diganti total dengan data dari file. Gunakan hanya jika KS beri tahu "sudah hapus X".
File JSON dari KS ditolak, kenapa?
3 kemungkinan: (1) NPSN tidak ada di daftar binaan Anda, (2) File dari pengawas lain (field pengawas_nip beda), (3) File corrupt. Minta KS kirim ulang.
Bagaimana jika KS pindah tugaskan?
Hubungi KS baru untuk akses laptop lama, atau hubungi KS lama langsung. Jika data tidak bisa diakses, mulai dari state terakhir yang Anda punya.
Data hilang setelah clear browsing, bisa pulih?
Tidak bisa kecuali ada backup JSON. Ini alasan backup mingguan wajib. Simpan di Google Drive dengan nama tanggal.
Klaim saya ditolak KS, kenapa?
KS bisa menolak klaim jika sekolah tersebut bukan wilayah binaan Anda. Hubungi Dinas untuk verifikasi wilayah. Atau coba klaim ulang jika KS salah klik.

Butuh bantuan? Hubungi Admin Dinas Pendidikan Kabupaten Wonogiri.
