Panduan Pengawas

Panduan lengkap penggunaan aplikasi SISPA Mandiri untuk Pengawas — dari instalasi, alur kerja agregasi data dari banyak KS, analisis kinerja, evaluasi, hingga cetak laporan ke Dinas Pendidikan.

Pengenalan

SISPA Pengawas adalah aplikasi semi-online untuk Pengawas Sekolah dalam mengelola data supervisi dari banyak sekolah binaan. Anda menerima file JSON dari setiap KS, mengimpor ke aplikasi, dan menganalisis hasilnya lintas sekolah.

Data disimpan lokal, bukan cloud Semua data tersimpan di laptop Anda (IndexedDB). Tidak ada server cloud. Untuk backup, ekspor seluruh data ke file JSON secara berkala.

Pasang & Akses Aplikasi

Sama seperti versi KS. Buka URL PS, install PWA, buka seperti aplikasi biasa.

Gunakan Chrome/Edge Desktop PS sebaiknya diakses dari laptop/PC, bukan HP, karena tabel analitik lebih nyaman di layar besar. HP bisa dipakai untuk impor cepat tapi tidak direkomendasikan untuk analisis.

Alur Kerja Pengawas

1. Terima JSON dari KS — via WhatsApp atau Email.
2. Import — dengan mode Merge atau Replace.
3. Dashboard — pantau agregat semua sekolah.
4. Analisis — benchmark coverage & kualitas.
5. Evaluasi KS — ranking + rekomendasi pembinaan.
6. Laporan — cetak rekap PDF atau ekspor CSV ke Dinas.

1. Terima JSON dari KS

KS akan mengirim file JSON via WhatsApp atau Email secara berkala (mingguan atau akhir semester). File contoh: SISPA_Backup_2026-10-20.json.

Simpan file ke folder lokal di laptop Anda, misal Dokumen/SISPA/[Nama Sekolah]/. Pisahkan per sekolah agar mudah dilacak.

2. Import File JSON

1
Buka menu "Sekolah Binaan"
Sidebar kiri.
2
Klik "Import JSON dari KS"
Tombol biru di kanan atas.
3
Pilih file JSON
Klik "Pilih File" atau drag-drop. Sistem akan analisis otomatis.
4
Review preview
Muncul dialog dengan info: nama sekolah, NPSN, KS, dan diff per jenis (X baru / Y update / Z sama).
5
Pilih mode & Import
Pilih Merge (aman, sync rutin) atau Replace (reset sekolah). Klik Import.

Mode Merge vs Replace — Kapan Pakai?

Situasi Mode Efek
Sync rutin (KS kirim tiap minggu) Merge Data lama dipertahankan, hanya item baru/diubah yang di-update. Aman.
KS beri tahu "saya hapus X, tolong update" Replace Data lama dihapus, diganti total dengan data dari file. Bersih tapi berisiko.
Sekolah baru pertama kali import — Otomatis ditambahkan (tidak perlu pilih mode).
Selalu backup sebelum Replace Replace akan menghapus data lama. Jika KS ternyata salah kirim file (data lama), data Anda hilang. Sebelum Replace, ekspor backup Pengawas dulu di Pengaturan.

3. Dashboard Agregat

Setelah import beberapa sekolah, dashboard menampilkan:

  • Total sekolah binaan
  • Total guru lintas sekolah
  • Total sesi supervisi (3T + Akademik + Coaching)
  • Distribusi tipe guru (Dropout/Unfocused/Analytical/Professional)
  • Chart sesi per sekolah (top 6)
  • Warning sekolah yang belum kirim data >30 hari
  • Aktivitas terbaru (6 sesi terakhir lintas sekolah)

4. Analisis & Benchmark

Menu Analisis & Benchmark. Fitur utama untuk membandingkan performa antar sekolah:

  • Coverage per sekolah — % guru yang sudah ≥1× disupervisi. Warna hijau (≥80%), kuning (50-79%), merah (<50%).
  • Rata-rata skor per sekolah — akademik (/76) dan coaching (/32).
  • Chart prinsip PM & pengalaman — agregat lintas sekolah.
  • 8 Dimensi Profil Lulusan — bar horizontal agregat.
  • Integrasi KKA — % sesi 3T yang menyertakan Koding/AI.

5. Evaluasi Kinerja KS

Menu Evaluasi Kinerja KS. Sistem memberi ranking KS berdasarkan 3 metrics weighted:

Metric Bobot Cara Hitung
Coverage 40% % guru yang sudah ≥1× disupervisi (3T/Ak/Co)
Volume 30% Sesi supervisi per guru (target 4 = 100%)
Kelengkapan RTL 30% % sesi dengan RTL terisi

Kategori:

  • 🥇 Sangat Baik — skor ≥85
  • 🥈 Baik — skor 70-84
  • 🥉 Cukup — skor 50-69
  • ⚠️ Perlu Pembinaan — skor <50

Sistem juga memberi rekomendasi otomatis per KS. Contoh: "Coverage 45% — prioritas pembinaan: jadwalkan supervisi untuk guru yang belum".

6. Laporan ke Dinas

Menu Laporan Rekap. Tiga jenis output:

A. Cetak Rekap Pengawas (1 halaman)

Ringkasan semua sekolah binaan: jumlah guru, sesi, coverage, skor, kategori. Format A4 dengan tanda tangan Kepala Dinas + Pengawas. Cocok untuk laporan bulanan/semester.

B. Cetak Rekap per Sekolah

Detail per sekolah: distribusi tipe guru, daftar guru dengan riwayat supervisi, dan tanda tangan KS + Pengawas. Untuk dokumentasi pembinaan per sekolah.

C. Export CSV

Tiga file CSV untuk Excel Dinas:

  • CSV Guru — data semua guru lintas sekolah + supervisi.
  • CSV Supervisi — semua sesi supervisi.
  • CSV Rekap — rekap per sekolah dengan metrics kinerja.

Detail Fitur

Data Guru Lintas Sekolah

Semua guru dari semua sekolah dalam satu tabel. Filter by sekolah, tipe, atau search nama/mapel/NIP. Klik Detail untuk melihat riwayat supervisi lengkap per guru.

Semua Supervisi

Semua sesi supervisi lintas sekolah, jenis, dan tanggal. Filter by sekolah/jenis/bulan/nama guru. Klik ikon mata untuk detail, ikon printer untuk cetak.

Backup & Restore

WAJIB: Backup mingguan Data Anda lebih banyak dan berharga dari KS (banyak sekolah). Backup mingguan minimal, sebaiknya setiap kali selesai batch import.

Backup

Pengaturan → Ekspor Backup. File JSON dengan semua data semua sekolah akan terunduh. Simpan ke Google Drive.

Restore

Pengaturan → Restore Backup → pilih file JSON → konfirmasi. Semua data saat ini akan diganti dengan data dari file.

FAQ & Troubleshooting

Berapa banyak sekolah yang bisa ditangani?
Secara teknis tidak ada batas keras — IndexedDB bisa menampung ratusan MB. Untuk 100-200 sekolah (20 guru × 30 sesi per sekolah) masih aman. Untuk >500 sekolah, pertimbangkan split per wilayah atau backup bulanan.
Import file yang sama berulang kali, aman?
Ya, aman di mode Merge. Sistem akan mendeteksi tidak ada yang baru, jadi tidak ada duplikasi. Ini yang direkomendasikan untuk sync rutin.
KS sudah hapus data, tapi file JSON saya masih ada. Gimana?
Import ulang file dengan mode Replace. Data lama yang ada di aplikasi akan diganti total dengan data dari file. Efeknya = "mengembalikan" state ke waktu file dibuat.
Bagaimana kalau KS pindah tugaskan tanpa kirim JSON final?
Hubungi KS baru untuk akses laptop lama, atau hubungi KS lama langsung. Jika data tidak bisa diakses, mulai dari state terakhir yang Anda punya (file JSON backup terakhir). Data setelahnya akan hilang, tapi data historis tetap utuh.
Bisa ganti nama sekolah yang sudah diimport?
Bisa. Menu Sekolah Binaan → klik ikon pensil (Edit) di baris sekolah. Bisa ganti nama, NPSN, nama KS, NIP KS. Data dalam tidak berubah.
Data saya hilang setelah clear browsing data. Bisa pulih?
Tidak bisa, kecuali Anda punya file backup JSON. Ini alasan mengapa backup mingguan wajib. Ke depannya: ekspor backup setelah setiap sesi batch import, simpan di Google Drive dengan nama tanggal.
CSV export tidak bisa dibuka di Excel?
Buka Excel → Data → From Text/CSV → pilih file → delimiter titik-koma → encoding UTF-8. Atau drag-drop file langsung ke Excel — biasanya otomatis handle.

Tips Profesional

Buat folder per sekolah di laptop Simpan setiap file JSON dari KS di Dokumen/SISPA/Nama Sekolah/. Beri nama dengan tanggal. Kalau perlu restore ke versi tertentu, mudah dicari.
Jadwal sync rutin Tetapkan jadwal: setiap Jumat minta KS kirim JSON mingguan, atau setiap akhir bulan untuk sekolah dengan volume rendah. Konsistensi lebih penting dari frekuensi.
Gunakan Evaluasi KS untuk pembinaan, bukan hukuman Ranking digunakan untuk mengidentifikasi KS yang perlu pendampingan intensif. Komunikasikan dengan suportif, bukan punitif.
Cetak rekap bulanan Cetak rekap Pengawas setiap akhir bulan, simpan di arsip. Bukti dokumentasi lengkap untuk Dinas, plus mudah dijadikan lampiran laporan tahunan.
Backup sebelum Replace Setiap kali mau pakai mode Replace, wajib backup dulu. Kebiasaan ini bisa menyelamatkan Anda dari kehilangan data tak terduga.

Butuh bantuan lebih lanjut? Hubungi admin Dinas Pendidikan atau tim teknis wilayah.
